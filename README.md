## 给 AI 的说明

如果你是被要求"接着学 / 复习"某个主题的 AI 助手：

1. 先读该主题的 `README.md`，再读 `学习档案-*.md`。档案里有**已确认掌握的知识**、**待讲的黑箱**、**踩过的坑**（学习者曾经理解错、已纠正过的地方）。
2. 讲解时只引用档案里已确认的概念，新概念要先解释再使用；"踩过的坑"里提到的类比和误区，讲相关内容时要避开或重点抽查。
3. 这些笔记是学习过程的记录，不是权威资料。具体事实以原始材料为准（每个主题的 README 里列了材料链接）。
